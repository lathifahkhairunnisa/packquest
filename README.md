# 🎒 The Digital Suitcase

**Pack smart. Travel ready.**

The Digital Suitcase adalah website interaktif yang mengajak pengguna memilih destinasi dan mengemas barang ke dalam koper digital dengan kapasitas terbatas.

## ✨ Features
- 5 pilihan destinasi perjalanan
- Interactive packing system
- Maximum suitcase capacity
- Dynamic travel challenge
- Packing score
- Good choices / Missing essentials / Unnecessary items analysis
- Dark mode
- Responsive design

## 🛠️ Built With
- HTML
- CSS
- Vanilla JavaScript

## 🚀 Run Locally
Extract the project and open `index.html` in a browser.

## 🌐 GitHub Pages
Upload all project files to a GitHub repository, then go to:

**Settings → Pages → Deploy from a branch → main → /(root)**

Save the settings and GitHub will provide a live website link.
